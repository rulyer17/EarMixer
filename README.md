# EarMixer

EarMixer is a Windows system-tray volume mixer with a compact microphone section integrated into the main flyout.

## What EarMixer adds

- Select the current recording device from the flyout.
- Adjust the selected microphone's Windows input level.
- Toggle microphone mute with a clear on/off state.
- Keep the original playback-device and per-app volume controls.

This portable build does not send crash reports or usage telemetry to the EarMixer project or to the upstream project.

## Run

Download the portable release, extract it, then run `EarMixer.exe`. It runs from the tray and does not require installation.
